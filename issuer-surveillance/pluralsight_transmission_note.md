# Pluralsight Transmission Note

As of 2026-04-19.

## Bottom line

Pluralsight is the cleanest live transmission case in the borrower database because it is no longer just a historical restructuring lesson. It is still sitting across multiple public BDC books, with non-accrual exposure already spread across several lenders and post-workout PIK still present in parts of the capital structure.

That makes it the best current cross-fund case for answering a portfolio-manager question that matters more than the single-name memo: where can one stressed software credit still leak through multiple public lenders at once?

## Why this matters now

The importance of Pluralsight is not that it is a mystery. The restructuring path is already well understood in [pluralsight_memo.md](D:/Dev/repos/private-credit-work/issuer-surveillance/pluralsight_memo.md). The importance is that the post-restructuring exposure is still broad enough to matter for live fund surveillance.

Three things make it especially valuable:

1. It is already a confirmed workout template.
The project does not need to guess what stress looks like here. We have already seen the sequence: software LBO optimism, operating underperformance, rate pressure, liability management, lender control, and debt-plus-equity recovery.

2. The exposure is still distributed across multiple public vehicles.
That means Pluralsight is not just a historical memo topic. It remains a useful lens on how different managers carry, mark, and absorb the same stressed software family.

3. The transmission path is visible at both the credit and fund level.
The borrower-family data says the stress is not isolated. The fund-level screen says some of the same lenders are already in caution or avoid buckets for their own reasons. That combination matters for portfolio construction.

## Most relevant funds to monitor through the Pluralsight lens

### `GSBD`

Pluralsight matters a lot here because GSBD is already in the caution bucket and has visible exposure history through both debt and equity. If GSBD keeps carrying soft earnings coverage while a name like Pluralsight stays stressed, the risk is not just one position mark. The risk is that weak portfolio carry and weak fund-level earnings reinforce one another.

### `OBDC`

OBDC is not currently in the danger bucket at the fund level, but Pluralsight is a reminder that scale and diversification do not eliminate transmission. This is exactly the kind of name that can keep a "generally okay" lender from re-rating upward if the software sleeve stays messy.

### `OCSL`

OCSL already screens as a more mixed story, and Pluralsight is one reason to keep it in the monitoring set rather than treating it as a simple discount opportunity.

### `OTF`

OTF is one of the better cheap names in the current decision pack, which is why Pluralsight matters so much here. If OTF is going to earn a "selective add" stance, we need confidence that its discount is not simply underpricing a broader software-mark problem. Pluralsight is one of the best names to test that.

### `TCPC`

TCPC is already in the avoid bucket on fund-level grounds. Pluralsight does not create the whole problem, but it does reinforce the case that the discount should not be treated as enough by itself.

## PM use

Use Pluralsight in three ways:

1. As the lead cross-fund borrower in the monthly watchlist.
If a borrower family needs one row that says "stress can travel," this is the one.

2. As the comparison case for software names that are not fully broken yet.
Medallia and Zendesk are more useful when set beside a case where the workout logic is already visible.

3. As a discipline check on discounted funds with software exposure.
Any time a fund looks optically cheap but still carries software concentration, ask whether Pluralsight-like recovery math is already reflected.

## What would change the view

The transmission case would get less important if one of two things happened:

- exposure shrinks materially across the public BDC set
- post-workout marks and accrual behavior stabilize enough that the name stops functioning as a live stress indicator

Until then, Pluralsight remains the most useful bridge between issuer surveillance and fund-level portfolio action in this repo.
